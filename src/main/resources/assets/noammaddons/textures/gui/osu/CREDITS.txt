default/.

             hitcircle@2x.png        -> hitcircle.png
             hitcircleoverlay@2x.png -> hitcircleoverlay.png
             approachcircle@2x.png   -> approachcircle.png
             lighting@2x.png         -> lighting.png

rafis/ - the "Rafis 2018-03-26 HDDT" skin
  Source:  https://skins.osuck.net/skins/166 (uploaded by ck; the page credits DDK RPK as the creator)
  Archive: "Rafis 2018-03-26 HDDT.osk", the `osk` upload on that page
  Files:   hitcircle.png, hitcircleoverlay.png, approachcircle.png, hit300.png, cursor.png, cursortrail.png -
           byte-identical to the archive
  Licence: none declared by the upload; kept for the owner's personal, non-commercial build only
  Note:    this skin's hit300.png is a 1x1 file, which is how osu! skins hide the judgement, so this skin draws no
           "300". It ships no lighting.png, so the default hit flash is used.
